# 正逆运动学解析解

## 1. 正运动学 (Forward Kinematics)

### 关键推导

由平行四边形 O-P1-P4-P3 可知: **P4 = P1 + P3**

由平行四边形 P1-P2-P6-P5 可知: **P6 = P2 + P5 - P1**

bar_d 为直杆 P4-P1-P5, 方向与 P3 共线反向:
**P5 = P1 - (32.4/57.3) × P3**

代入得:
**P6 = P2 - (32.4/57.3) × P3 = P2 - 32.4 × [cos(θ_b), sin(θ_b)]**

bar_f 为直杆 P6-P2-P7, P7 在 P2→P6 的反方向:
**P7 = P2 + 128 × [cos(θ_b), sin(θ_b)]**

又 P2 = 107.4 × [cos(θ_a), sin(θ_a)], 代入得:

### 解析公式

```
P7_x = L1 · cos(θ_a) + L2 · cos(θ_b)
P7_y = L1 · sin(θ_a) + L2 · sin(θ_b)
```

其中 **L1 = 107.4 mm** (|O-P2|), **L2 = 128 mm** (|P2-P7|).

**物理意义**: 机构等价于一个 2R 平面机械臂!
- 第一连杆: O→P2  (长 107.4 mm, 角度 θ_a)
- 第二连杆: P2→P7 (长 128 mm, 角度 θ_b)

## 2. 逆运动学 (Inverse Kinematics)

给定末端位置 P7 = (x, y), 求电机转角 θ_a, θ_b.

### 求解

令 r = √(x² + y²), 由余弦定理:

```
cos(α) = (r² + L1² - L2²) / (2 · L1 · r)
```

其中 α 是向量 (x, y) 与第一连杆方向之间的夹角.

则:
```
θ_a = atan2(y, x)  ±  arccos(cos(α))
θ_b = atan2(y - L1·sin(θ_a),  x - L1·cos(θ_a))
```

**±** 对应两个解 (肘向上 / 肘向下).

### 工作空间

```
|L1 - L2| ≤ r ≤ L1 + L2
20.6 mm ≤ r ≤ 235.4 mm
```

### 奇异位形

1. **r = L1 + L2 = 235.4 mm** (完全伸展): α = 0, 单解 (θ_a = θ_b)
2. **r = |L1 - L2| = 20.6 mm** (完全收缩): α = π, 单解
3. **r = 0** (原点): 无穷多解
