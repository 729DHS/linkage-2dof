# 2-DOF 轮腿机器人连杆机构 — 机构说明

## 1. 机构拓扑

两个电机轴同轴重合于原点 O，分别驱动杆 A 和杆 B。
机构由两个平行四边形以 8 字形连接而成。

```
Motor A, B (coaxial)
       O
      / \
  bar_a   bar_b
  (直杆)  (二元)
  /   \    |
P1    P2   P3
 |     |    |
 |     |   bar_c (48.4)
 |     |    |
bar_d  |   P4
(直杆) |  /
 |  \  | /
P4  P5 P1 (AD连接, 共用)
   \ | /
  bar_e  bar_d
    |      |
   P6 --- P2 (AF连接, 共用)
    \     /
    bar_f (直杆)
      |
      P7 (轮毂电机)
```

## 2. 平行四边形关系

### 平行四边形 1: O-P1-P4-P3
| 边 | 对边 | 长度 (mm) |
|----|------|-----------|
| O-P1 | P3-P4 | 48.4 = 48.4 |
| O-P3 | P1-P4 | 57.3 = 57.3 |

### 平行四边形 2: P1-P2-P6-P5
| 边 | 对边 | 长度 (mm) |
|----|------|-----------|
| P1-P2 | P5-P6 | 59 = 59 |
| P1-P5 | P2-P6 | 32.4 = 32.4 |

## 3. 杆件参数 (mm)

所有三元杆都是直杆 (collinear), 第二点位于第一和第三点之间。

| 杆 | 类型 | 点 | 长度 (mm) | 说明 |
|---|------|----|-----------|------|
| bar_a | 直杆 | O — P1(AD) — P2(AF) | \|O-P1\|=48.4, \|P1-P2\|=59, \|O-P2\|=107.4 | |
| bar_b | 二元 | O → P3 | 57.3 | |
| bar_c | 二元 | P3 → P4 | 48.4 | |
| bar_d | 直杆 | P4(CD) — P1(AD) — P5(DE) | \|P4-P1\|=57.3, \|P1-P5\|=32.4, \|P4-P5\|=89.7 | |
| bar_e | 二元 | P5 → P6 | 59 | |
| bar_f | 直杆 | P6(EF) — P2(AF) — P7(Wheel) | \|P6-P2\|=32.4, \|P2-P7\|=128, \|P6-P7\|=160.4 | |

## 4. 运动学求解（解析解）

### Step 1: 由 θ_a 求 P1, P2
bar_a 为直刚体, 局部坐标:
- P1_local = (48.4, 0)
- P2_local = (107.4, 0)
- 全局: P1 = R(θ_a) × P1_local, P2 = R(θ_a) × P2_local

### Step 2: 由 θ_b 求 P3
- P3 = 57.3 × (cos θ_b, sin θ_b)

### Step 3: 求 P4 (两圆交点)
- 圆1: 中心 P1, 半径 r1 = |P1-P4| = 57.3
- 圆2: 中心 P3, 半径 r2 = |P3-P4| = 48.4
- 有两解, 由 branch_d 选择

### Step 4: 求 bar_d 方向角和 P5
- θ_d = atan2(P4 - P1)
- P5_local = (-32.4, 0)  (P5 在 P1 的 P4 反向)
- P5 = P1 + R(θ_d) × P5_local

### Step 5: 求 P6 (两圆交点)
- 圆1: 中心 P2, 半径 r1 = |P2-P6| = 32.4
- 圆2: 中心 P5, 半径 r2 = |P5-P6| = 59
- 有两解, 由 branch_f 选择

### Step 6: 求 bar_f 方向角和 P7 (轮毂电机)
- θ_f = atan2(P6 - P2)
- P7_local = (-128, 0)  (P7 在 P2 的 P6 反向)
- P7 = P2 + R(θ_f) × P7_local
