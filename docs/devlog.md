# 开发日志 (DevLog)

## 目标

制作轮腿机器人 2-DOF 连杆机构的 Python 仿真。
- 两个电机同轴驱动
- 机构由两个平行四边形以 8 字形连接
- 末端为轮毂电机
- 求解末端轨迹与电机转角的关系（解析解）
- 杆长可调

## 2026-05-04 (早期): 项目初始化

### 问题1: 默认参数导致无解

**问题**: 初始默认参数 (随意选的) 大量角度无解

**原因**: 杆长不匹配, 两圆相交条件不满足

**解决**: 改用用户提供的实际参数后, 100% 配置有效

### 问题2: bar_a 共线建模

**问题**: 原代码假设 bar_a 的 P1 和 P2 与 O 共线

**决策**: 用户确认所有杆都是直杆, 共线建模正确

### 问题3: 直杆的三角形表示

**问题**: 直杆三点共线, 第三边是第一+第二边之和

**验证**: triangle_solve_local 函数对 cos(α)=1 或 -1 能正确处理:
- P2 与 P1 在 O 同侧: cos(α)=1, P2_local=(+107.4, 0)
- P5 与 P4 在 P1 异侧: cos(α)=-1, P5_local=(-32.4, 0)
- P7 与 P6 在 P2 异侧: cos(α)=-1, P7_local=(-128, 0)

### 问题4: 装配分支选择

**问题**: 两个两圆相交步骤各有两解

**解决**: branch_d=-1, branch_f=-1 对应正确的平行四边形装配模式

---

### 问题5: 平行四边形凹凸性

**问题**: branch_d=-1 默认对应交叉四边形 (crossed), 不是凸四边形

**解决**: 
- 默认改为 branch_d=+1 (在 θ_a=0°, θ_b=90° 时对应凸四边形)
- 添加 `solve_all_branches()` 函数, 一次输出全部 4 种装配模式
- 添加 `plot_all_branches()` 可视化, 并排显示所有有效解
- 用 `python -m src.main branches` 查看所有解

**注意**: convex/crossed 对应的 branch 不是固定的, 随角度变化。
轨迹跟踪用 continuity tracking (prev_theta_d) 保持一致性。

---

### 问题6: 默认分支确认

**问题**: 用户需要知道默认是哪个装配模式, 不能随意选择

**确认**: 
- 默认 `branch_d=+1, branch_f=-1` = 凸四边形 (convex parallelogram)
- 这是正运动学解析公式 `P7 = L1*[cos θa, sin θa] + L2*[cos θb, sin θb]` 对应的分支
- 在所有测试角度下验证通过 (|P4 - (P1+P3)| ≈ 0)

**文档**: 添加了详细的 `docs/USAGE.md` (中英双语), 涵盖:
- 所有 7 种运行模式说明
- 交互界面各元素说明
- 默认参数完整列表
